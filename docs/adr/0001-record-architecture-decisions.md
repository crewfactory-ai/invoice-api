# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-11-01

## Context

Decisions about this service are made in pull request threads and are hard to find later.

## Decision

We record each significant decision as a short numbered file in `docs/adr/`. A decision that is
replaced keeps its file, and its status names the decision that replaces it.

## Consequences

A reviewer can ask for an ADR when a change makes a decision that others must follow.
